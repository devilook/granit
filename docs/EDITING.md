# Как менять сайт

Короткая шпаргалка: где лежит каждая вещь и как её поменять, не ломая остальное.
После любой правки: `npm run dev` → http://localhost:5173 (страница обновится сама).

## Карта

| Хочу поменять… | Файл |
|---|---|
| Текст в любом блоке | `src/sections/<секция>.html` |
| Вид одного блока (отступы, размеры, расположение) | `src/sections/<секция>.css` |
| Цвета, шрифты, размеры текста, отступы, скругления — **для всего сайта сразу** | `src/styles/tokens.css` |
| Кнопки, подписи, общие стили | `src/styles/base.css` |
| Порядок блоков на странице, убрать/добавить блок | `index.html` (список `<include>`) |
| Телефон, мессенджеры, адрес | `src/config/content.js` → `CONTACTS` |
| Столы в коллекции (названия, камни, размеры, цены, фото) | `src/config/content.js` → `COLLECTION` |
| Стол на главном экране | `src/config/content.js` → `HERO.table` |
| Цвета камней | `src/gl/stone.js` → `STONES` |
| Форма плиты, толщина, скол, опоры | `src/gl/table.js` |
| Поведение 3D: насколько стол двигается за мышью, свет | `src/gl/hero.js` (константы вверху и функция `place`) |
| Анимации появления, скорость прокрутки | `src/ui/motion.js` |
| Отправка формы | `src/ui/form.js` |
| Фото | `public/media/` (ссылка в HTML: `./media/имя.webp`) |

Секции: `nav`, `hero`, `philosophy`, `collection`, `process`, `trust`, `lead`, `footer` —
у каждой пара файлов `.html` + `.css` с одинаковым именем в `src/sections/`.

## Частые задачи

**Поменять текст.** Открыть `src/sections/<секция>.html`, исправить текст между тегами. Атрибуты
(`class`, `data-…`) не трогать — на них держатся стили и анимации.

**Поменять цвет акцента / фона / текста на всём сайте.** `src/styles/tokens.css`:
`--c-accent` (латунь на тёмном), `--c-accent-ink` (тот же акцент на светлом), `--c-page`
(фон страницы), `--c-card` (тёмные карточки), `--c-ink` (текст). Одна строка — меняется везде.

**Поменять шрифт.** В `index.html` поправить ссылку Google Fonts, в `tokens.css` — `--f-sans`
(основной) или `--f-serif` (курсив-акцент).

**Добавить стол в коллекцию.** В `src/config/content.js` скопировать строку в `COLLECTION`,
поменять `id` (латиницей, уникальный), `name`, `stone`, размеры, `price`, `seed`
(другое число = другой контур и рисунок). Линия: `...rock` («Скала») или `...classic` («Классика»).
Когда будут фото: `photos: { top: './media/stol-verh.webp', raw: './media/stol-niz.webp' }`.

**Добавить новый камень.** В `src/gl/stone.js` в `STONES` скопировать палитру и подобрать цвета:
`a` — самый тёмный фон, `b` — средний, `c` — светлые кристаллы, `s` — вкрапления;
`scale` — крупность зерна (меньше = крупнее).

**Убрать блок со страницы.** В `index.html` удалить строку `<include src="trust.html" />`
(и при желании `@import` его CSS в `src/styles/main.css`).

**Поменять блоки местами.** Переставить строки `<include …>` в `index.html`.

**Добавить новый блок.** Скопировать `src/sections/_template.html` и `_template.css`,
переименовать (например `reviews.html` / `reviews.css`), заменить класс `example` на свой,
добавить `<include src="reviews.html" />` в `index.html` и
`@import '../sections/reviews.css';` в `src/styles/main.css`.
Готовые «помощники» для разметки:
- `data-reveal` — элемент плавно появляется при прокрутке;
- `data-lines` + `<span class="line"><span>…</span></span>` — заголовок выезжает построчно;
- `data-torn="число"` — рваный нижний край (как скол), число = форма края;
- классы `container`, `grid` (12 колонок), `section` (вертикальные отступы), `label`, `display-2`,
  кнопки `pill pill--accent` / `pill pill--line`.

**Стол на главной двигается слишком сильно/слабо.** `src/gl/hero.js`, функция `place`:
`vx * 0.2` — поворот за мышью (радианы), `vy * 0.07` — наклон. `STIFFNESS`/`DAMPING`
вверху файла — «тяжесть» движения.

## Адаптив

Три точки перелома, одинаковые во всех файлах: `1180px` (ноутбук), `960px` (планшет),
`560px` (телефон). Правила для мобильных лежат в конце CSS-файла своей секции.

## Перед публикацией

```bash
npm run build     # должна пройти без ошибок
npm run preview   # проверить собранную версию
```

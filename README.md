# ГРАНЬ — сайт столов из цельного гранита

Одностраничный сайт: живой 3D-стол на главном экране, две линии коллекции
(«Скала» и «Классика»), производство, расчёт.
Концепция и дизайн-система: [`docs/CONCEPT.md`](docs/CONCEPT.md).

## Запуск

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # продакшн-сборка в dist/
npm run preview        # посмотреть сборку
npm run build:single   # один самодостаточный HTML в dist-single/ (для показа)
```

Нужен Node 18+. Хостинг подойдёт любой статический: Netlify, Vercel, Nginx, S3.

## Стек

Vite, Three.js (3D-стол и снимки коллекции), GSAP + ScrollTrigger (анимации),
Lenis (инерционная прокрутка). Фреймворка нет: модули `src/gl/*` и `src/ui/*`
без изменений переносятся в Next.js, когда дойдём до функций.

```
index.html               каркас: список секций <include src="…" />
src/sections/*.html|css  каждая секция страницы — свой HTML и свой CSS
src/styles/tokens.css    цвета, шрифты, отступы для всего сайта
src/main.js              сборка всего: hero, выноски, анимации
src/config/content.js    ← все данные: контакты, стол на главной, коллекция
src/gl/table.js          генератор стола: контур, полировка, скол, опоры
src/gl/stone.js          процедурный гранит (палитры камней)
src/gl/hero.js           сцена главного экрана, свет, реакция на мышь
src/gl/stills.js         рендер снимков для карточек коллекции
src/ui/*                 курсор, рваные края, контуры, форма, скролл
src/styles/*             токены, база, секции
public/media/            фото из цеха (ваши)
```

**Как быстро менять тексты, блоки, цвета и добавлять секции — [`docs/EDITING.md`](docs/EDITING.md).**

## Что заменить (поиск по `REPLACE_ME`)

| Что | Где |
|---|---|
| Телефон, WhatsApp, Telegram, почта, адрес | `src/config/content.js` → `CONTACTS` |
| Стол на главной (камень, размер, форма; `seed` — другой контур и рисунок) | `content.js` → `HERO.table` |
| Видео вместо 3D (если снимете ролик) | `content.js` → `HERO.mode = 'video'`, `HERO.video.src/poster` |
| Макрофото кромки в «Философии» | `content.js` → `PHILOSOPHY.photo` (пусто = рендер 3D) |
| Столы коллекции: названия, камни, размеры, цены | `content.js` → `COLLECTION` |
| Фото столов в коллекции (верх + скол/кромка) | `COLLECTION[i].photos.top / .raw` (пусто = рендер 3D) |
| Цвета камней под ваши реальные блоки | `src/gl/stone.js` → `STONES` |
| Фото цеха в «Производстве» | `public/media/*.webp`, разметка в `src/sections/process.html` |
| Отправка заявки (CRM / Telegram-бот) | `src/ui/form.js` → место с `REPLACE_ME` |
| Тексты блоков | `src/sections/*.html` |

Названия камней «Серо-зелёный гранит», «Тёплый бежевый гранит» и т. п. — рабочие.
Подставьте реальные названия и месторождения ваших блоков.

## Поведение

- **Главный экран:** стол реагирует на мышь с небольшой амплитудой (поворот до ±12°, наклон до ±4°),
  блик в полировке проходит дальше, чем движется сам камень. Выноски привязаны к точкам
  модели и двигаются вместе с ней. Вес на выноске рассчитывается из геометрии плиты.
- **Телефон:** стол медленно «дышит» сам, выноски скрыты, вёрстка в одну колонку.
- **prefers-reduced-motion:** один статичный кадр, без анимаций и инерции, всё видно сразу.
- **Без WebGL:** показывается видео или постер из `HERO.video`.
- 3D подгружается после первой отрисовки текста; рендер останавливается, когда главный экран
  вне видимости или вкладка скрыта.
